# ADR 0001 — Deterministic Synthetic Commercial Data

- **Status:** Accepted
- **Date:** 2026-07-29

## Decision

Use approximate public-place geography for context and generate every commercial,
demographic, demand, cost and performance result deterministically with seed 20260729.

## Consequences

The project is reproducible and contains no personal or proprietary store performance.
Model metrics cannot be claimed as real-world accuracy, and every output must remain
labelled as synthetic decision support.
