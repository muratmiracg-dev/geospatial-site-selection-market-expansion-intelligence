# Stage 1 Review Handoff

## Review order

1. Read the executive summary in the presentation and PDF.
2. Inspect the Excel dashboard and candidate formulas.
3. Explore the candidate, white-space, isochrone and scenario HTML maps.
4. Review `artifacts/metrics/pipeline_summary.json` and quality evidence.
5. Challenge scoring directions/weights and scenario constraints.
6. Review limitations, risk register, threat model and branch protection guide.
7. Confirm the repository tree and manifest before authorizing publication.

## Publication boundary

Stage 1 creates a local `main` repository and review package only. It does not add a
remote, push, open a pull request or perform another GitHub write.

Publication may begin only after an explicit message in the form:

`Onaylıyorum. GitHub deposu: [DEPO_LINKİ]. main dalında yayınlayabilirsin.`

Any mandatory change between approval and publication must be disclosed, justified,
retested and reflected in the manifest.
